# Smart Complex — структура проекта

Обычный статический сайт: HTML + CSS + JS + картинки. Никаких сборщиков,
Node.js или установки пакетов не нужно — просто открываете `index.html`
в браузере.

## Структура файлов

```
smart-complex/
├── index.html          ← главная страница (три комплекса, дизайн дома)
├── vobkent.html         ← страница комплекса «Вобкент»
├── sheykhoncha.html     ← страница комплекса «Шейхонча»
├── safkarda.html        ← страница комплекса «Сафкарда»
├── css/
│   └── style.css       ← все стили (общие для всех страниц)
├── js/
│   ├── main.js          ← переводы RU/UZ/EN, слайдер, планировки — только на index.html
│   └── complex.js       ← схема выбора дома + слайдер/планировки — на страницах комплексов
└── images/              ← все фото и рендеры (обычные .jpg файлы, общие для всех страниц)
```

При клике на карточку комплекса на главной странице человек попадает на его
отдельную страницу — как на сайтах продажи билетов, где сначала выбираешь
мероприятие, а потом место в зале.

## Что на странице комплекса (vobkent.html / sheykhoncha.html / safkarda.html)

1. **Хиро** — фото комплекса, название, локация, количество домов
2. **О комплексе** — описание
3. **Инженерия и оборудование** — 8 карточек: солнечные панели, бойлер,
   ветрогенератор, тёплый водяной контур, зарядка для электромобиля,
   фильтрация воды, видеонаблюдение/умный домофон, резервный генератор
4. **Выбор дома** — интерактивная схема номеров домов (как выбор мест на
   концерт): клик по свободному (светлому) номеру открывает справа карточку
   с параметрами участка и кнопкой «Оставить заявку»
5. **Дизайн дома** — тот же слайдер рендеров и планировки, что на главной
6. **Фото комплекса** и футер со ссылкой обратно на главную

### ⚠️ Про схему выбора дома
Статусы домов (свободен / забронирован / продан) сейчас **сгенерированы
автоматически** для примера — это не настоящая база данных. Кнопка
«Оставить заявку» ничего никуда не отправляет, только показывает
подтверждение на странице. Чтобы это стало по-настоящему рабочим, нужно:
- подключить бэкенд/CRM (или Google-таблицу через форму) для реальных
  статусов домов;
- заменить фейковую отправку в `js/complex.js` (функция `initPlotSelector`,
  обработчик `plotRequestBtn`) на настоящий запрос (fetch на ваш сервер,
  Telegram-бот, амо CRM и т.п.).

Логика генерации сетки — в `js/complex.js`, функция `initPlotSelector(config)`.
Количество домов и диапазон площади участка задаются в конце каждой
HTML-страницы, например (safkarda.html):
```js
initPlotSelector({
  containerId: 'plotGrid',
  count: 36,
  areaMin: 7,
  areaMax: 10,
  houseArea: '250 м²',
  priceNote: 'по запросу',
});
```

## Как открыть и посмотреть сайт

1. Распакуйте архив целиком в одну папку (не вынимайте отдельные файлы —
   `index.html` ищет `css/style.css`, `js/main.js` и `images/...` рядом с собой).
2. Дважды кликните `index.html` — откроется в браузере по умолчанию.
   Либо: правой кнопкой → «Открыть с помощью» → выбрать браузер.
3. Для удобной разработки в VS Code: установите расширение **Live Server**,
   откройте папку проекта, правой кнопкой по `index.html` →
   **Open with Live Server** — сайт откроется с автообновлением при сохранении.

## Как вносить правки

### Поменять текст
Ищите нужную фразу прямо в `index.html` — там есть атрибуты `data-i18n="..."`.
Текст внутри тега — это то, что видно по умолчанию (русский). Но сайт также
подтягивает переводы из `js/main.js` (объект `dict.ru / dict.uz / dict.en`) —
если меняете текст, меняйте **в обоих местах**: и в `index.html`, и в
соответствующем ключе внутри `dict` в `main.js`, иначе при переключении
языка старый текст вернётся обратно.

Пример: чтобы поменять заголовок хиро-блока — ищите
`data-i18n-lines="hero.title"` в `index.html`, и `hero.title` внутри
`dict.ru` в `main.js`.

### Поменять фото
1. Положите новый файл в папку `images/` (можно с любым именем).
2. В `index.html` найдите нужный `<img src="images/старое-имя.jpg">`
   и замените имя файла на новое.

Карточки комплексов:
- Шейхонча → `images/card-sheykhoncha.jpg`
- Вобкент → `images/card-vobkent.jpg`
- Сафкарда → `images/card-safkarda.jpg`

Слайдер «Дизайн дома» → `images/house-1.jpg` … `images/house-8.jpg`
(в `index.html` секция `id="house"`, там же дублируются в миниатюрах).

Планировки этажей → `images/floorplan-1.jpg` (1 этаж),
`images/floorplan-2.jpg` (2 этаж).

### Поменять цвета/шрифты
Все цвета собраны в самом верху `css/style.css`, в блоке `:root { ... }`:

```css
--ink:   #171310;   /* тёмный фон (шапка, подвал, слайдер) */
--paper: #f5f0e6;   /* светлый фон страницы */
--sand:  #b99b6b;   /* акцентный цвет (кнопки, подсветка) */
--clay:  #6e4529;   /* цвет эйбров/надписей над заголовками */
```
Поменяйте значение — обновится весь сайт, так как остальные стили ссылаются
на эти переменные.

### Добавить новый комплекс / новую карточку
В `index.html` найдите блок `<div class="cx-grid">` — там три `<a class="cx-card">`.
Скопируйте один целиком, вставьте после третьего, поменяйте фото, текст и
`data-i18n` ключи на новые (и добавьте эти новые ключи в `dict` в `main.js`
для всех трёх языков, если нужен перевод).

### Добавить блок «Дизайн дома 2» / ещё один типовой дом
Секция `id="house"` и `id="floorplan"` в `index.html` — можно скопировать
целиком обе секции, дать новым id (`house-2`, `floorplan-2`), поменять
картинки и JS-обработчики в `main.js` (там, где `getElementById('houseSlider')`
и т.п. — понадобятся уникальные id, если хотите второй независимый слайдер).

## Языки (RU / UZ / EN)

Переключатель вверху сайта хранит выбор в `localStorage`, чтобы при
следующем визите не сбрасывался. Логика — в конце `js/main.js`,
объект `dict`. Каждый язык — отдельный блок `ru: {...}`, `uz: {...}`,
`en: {...}` с одинаковыми ключами.

## Важно про изображения
